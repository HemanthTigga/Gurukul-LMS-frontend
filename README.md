
# Gurukul

• Gurukul is a learning management system (LMS) focused on simplifying course management and content delivery.

• Provide features such as user-friendly access to learning resources, communication tools and assessment features to enhance online learning.

## Installation

Install my-project with npm

Frontend:-
```bash
  cd my-app
  npm install
  npm start
```
Backend:-
```bash
  cd server
  npm install
  npm start
```
## Tech Stack

**Client:** React.js, TailwindCSS, Three.js, MaterialUI

**Server:** Node, Express

**Database:** MongoDB
